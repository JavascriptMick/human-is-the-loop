# Human IS The Loop

**Embedding user first, voice enabled agents into mobile with Flutter and Gemini.**

Autonomous agents have a trust problem, and "human in the loop" doesn't fix it: a prompt asking the user for approval is a hack, not a partnership. This talk flips it around. The human is the loop, and the agent works inside the user's own loop, bearing their cognitive load instead of adding to it.

Four principles guide the design: understand the user's intent, respond to changes but take notes, be an expert, and no magic. The talk then shows them in practice with recipes4me, a hands-free cooking app, and walks through a custom in-app harness built with Flutter, Signals and Gemini that supports voice, intent tools and orchestrated flows driving the app's own screens.

A talk by Michael Dausmann, presented at Google DevFest 2026.
